# ⚡ Guía Maestra de Verbos en Alemán (Stammformen, Regímenes y Casos)

Esta guía complementa las herramientas del agente **DeutschMeister Lehrer**, detallando los patrones morfológicos más cruciales del sistema verbal alemán, sus formas básicas (*Infinitiv - 3. Person Präsens - Präteritum - Partizip II*) y la asignación estricta de casos (*Rektion der Verben*).

---

## 1. Las 3 Formas Básicas (*Die drei Stammformen*)

Para dominar cualquier verbo en alemán hay que memorizar sus tres pilares:
1. **Infinitiv**: la forma del diccionario.
2. **Präteritum** (3ª persona singular): base del pasado escrito y formal.
3. **Partizip II (+ Hilfsverb haben / sein)**: base del pasado hablado (*Perfekt*), pluscuamperfecto y voz pasiva.

---

## 2. Los Verbos con Auxiliar *SEIN* en Perfekt

En alemán, el 90% de los verbos forman el *Perfekt* con **haben**. Solo un grupo específico utiliza **sein**:
1. **Verbos de movimiento con cambio de lugar o dirección**:
   - *gehen* (ist gegangen), *fahren* (ist gefahren), *fliegen* (ist geflogen), *laufen* (ist gelaufen), *kommen* (ist gekommen), *reisen* (ist gereist), *schwimmen* (ist geschwommen).
   - Separables de movimiento: *abfahren, ankommen, einsteigen, aussteigen, mitkommen, umziehen*.
2. **Verbos de cambio de estado o condición**:
   - *aufstehen* (ist aufgestanden), *aufwachen* (ist aufgewacht - despertarse), *einschlafen* (ist eingeschlafen - dormirse), *sterben* (ist gestorben - morir), *wachsen* (ist gewachsen - crecer).
3. **Los 3 verbos especiales de permanencia o suceso**:
   - *sein* (ist gewesen), *bleiben* (ist geblieben), *passieren / geschehen* (ist passiert - ocurrir).

## 3. Verbos con Régimen de Caso Obligatorio

### A. Verbos que Rigen DATIVO (¡Trampas para hispanohablantes!)
En español decimos "le ayudo" o "lo ayudo", pero en alemán estos verbos **NUNCA** llevan acusativo:
- **helfen**: *Ich helfe DIR* (Te ayudo a ti).
- **danken**: *Ich danke IHNEN* (Le agradezco a usted).
- **gefallen**: *Das gefällt MIR* (Eso me gusta).
- **gehören**: *Das Auto gehört MEINEM Vater* (El coche le pertenece a mi padre).
- **schmecken**: *Die Pizza schmeckt UNS* (La pizza nos sabe rica).
- **passen**: *Die Zeit passt MIR gut* (La hora me viene bien).
- **antworten**: *Er antwortet DEM Chef* (Él responde al jefe).
- **gratulieren**: *Wir gratulieren DIR zum Geburtstag* (Te felicitamos por tu cumpleaños).
- **fehlen**: *Du fehlst MIR* (Me haces falta / Te echo de menos).

---

### B. Los Pares de Posición vs Colocación (*Wechselpräpositionen*)

| Acción (¿Wohin? + Acusativo + Regular) | Estado / Resultado (¿Wo? + Dativo + Irregular) |
| :--- | :--- |
| **stellen** (poner de pie) $\rightarrow$ *Ich stelle die Vase auf den Tisch.* | **stehen** (estar de pie) $\rightarrow$ *Die Vase steht auf dem Tisch.* |
| **legen** (tumbar / acostar) $\rightarrow$ *Ich lege das Buch auf das Bett.* | **liegen** (estar tumbado) $\rightarrow$ *Das Buch liegt auf dem Bett.* |
| **setzen** (sentar / colocar) $\rightarrow$ *Ich setze das Kind auf den Stuhl.* | **sitzen** (estar sentado) $\rightarrow$ *Das Kind sitzt auf dem Stuhl.* |
| **hängen** (colgar algo - reg.) $\rightarrow$ *Ich hänge das Foto an die Wand.* | **hängen** (estar colgado - irreg.) $\rightarrow$ *Das Foto hängt an der Wand.* |

## 4. Verbos con Preposiciones Fijas (Nivel A2 - B1)

| Verbo | Preposición y Caso | Pregunta para cosas | Ejemplo |
| :--- | :--- | :--- | :--- |
| **warten** | **auf** + Akkusativ | *Worauf?* | *Ich warte auf den Bus.* |
| **denken** | **an** + Akkusativ | *Woran?* | *Er denkt an seine Zukunft.* |
| **sich freuen** | **auf** + Akkusativ *(futuro)* | *Worauf?* | *Wir freuen uns auf die Ferien.* |
| **sich freuen** | **über** + Akkusativ *(presente)* | *Worüber?* | *Ich freue mich über das Geschenk.* |
| **sich interessieren** | **für** + Akkusativ | *Wofür?* | *Sie interessiert sich für Kunst.* |
| **bitten** | **um** + Akkusativ | *Worum?* | *Darf ich um Ruhe bitten?* |
| **träumen** | **von** + Dativ | *Wovon?* | *Er träumt von einem schnellen Auto.* |
| **teilnehmen** | **an** + Dativ | *Woran?* | *Ich nehme an der Konferenz teil.* |
| **sich beschweren** | **über** + Akkusativ | *Worüber?* | *Der Kunde beschwert sich über den Service.* |

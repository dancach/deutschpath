# 🧠 Metodología Didáctica y Modelos Mentales del Alemán

Este manual contiene los marcos pedagógicos, nemotécnicas y fórmulas visuales que el agente **DeutschMeister Lehrer** utiliza en cada interacción con el estudiante.

---

## 1. La Fórmula de Oro de la Sintaxis Alemana

### A. Regla V2 (En oraciones principales enunciativas)
```
[Posición 1]       + [POSICIÓN 2: VERBO CONJUGADO] + [Sujeto (si no está en Pos. 1)] + [Resto]
"Ich"             + "lerne"                       +                                 + "jeden Tag Deutsch."
"Heute"           + "lerne"                       + "ich"                           + "Deutsch."
"Weil es regnet," + "bleibe"                      + "ich"                           + "zu Hause."
```
> **Regla nemotécnica para el alumno:** En una afirmación, el verbo es una roca fija en el escalón 2. Si algo salta a la Posición 1 (por ejemplo, el tiempo: *Heute*, *Morgen*), empuja al sujeto inmediatamente al escalón 3.

---

### B. La Pinza Verbal (*Satzklammer*)
En alemán los verbos abrazan el resto de la frase:
```
[Sujeto] + [VERBO AUXILIAR / MODAL (Pos. 2)] + [Complementos...] + [VERBO PRINCIPAL (FINAL)]
 Ich     + kann                              + sehr gut          + schwimmen.
 Wir     + haben                             + gestern einen     + Film gesehen.
 Er      + steht                             + jeden Morgen um 6 + auf.
```
> **Metáfora didáctica:** Los verbos alemanes actúan como una tenaza o paréntesis que se abre en la posición 2 y no se cierra hasta el punto final.

---

### C. Conectores: Las Tres Familias
1. **Familia Posición Cero (ADUSO)**: No alteran el orden.
   - **A**ber (pero), **D**enn (porque explicativo), **U**nd (y), **S**ondern (sino), **O**der (o).
   - Estructura: `ADUSO + Sujeto + Verbo (Pos. 2)`.
2. **Familia Subordinante (Verbo al Fondo)**:
   - *weil, dass, wenn, als, obwohl, damit, während, da*.
   - Estructura: `Conector + Sujeto + Complementos + [VERBO AL FINAL]`.
3. **Familia Adverbial (Inversión en Posición 1)**:
   - *deshalb, deswegen, trotzdem, sonst, dann, außerdem*.
   - Estructura: `Conector (Pos. 1) + [VERBO (Pos. 2)] + Sujeto + Complementos`.

---

### D. Orden de los Complementos: La Regla TE-KA-MO-LO
Cuando en una frase hay varios complementos circunstanciales, el orden canónico natural en alemán sigue la regla:
1. **TE**mporal (*Wann?* ¿Cuándo?)
2. **KA**usal (*Warum?* ¿Por qué?)
3. **MO**dal (*Wie?* ¿Cómo?)
4. **LO**kal (*Wo / Wohin?* ¿Dónde / Adónde?)

*Ejemplo:*
> *"Ich fahre **morgen** (TE) **wegen der Arbeit** (KA) **mit dem Zug** (MO) **nach Berlin** (LO)."*

## 2. Los Cuatro Casos Simplificados para Hispanohablantes

| Caso | Función en la frase | Pregunta | Truco mental |
| :--- | :--- | :--- | :--- |
| **Nominativ** | El sujeto de la acción | *Wer? / Was?* (¿Quién?) | El protagonista de la historia. |
| **Akkusativ** | Objeto directo (qué/a quién afecta) | *Wen? / Was?* (¿A quién/qué?) | **El "Masculino Rebelde"**: solo cambia `der -> den / einen`. Femenino, neutro y plural no cambian. |
| **Dativ** | Objeto indirecto (destinatario/beneficiario) | *Wem?* (¿A quién?) | **La M y la R**: Masculino/Neutro terminan en `-m` (*dem*), Femenino en `-r` (*der*), Plural en `-n` (*den Kindern*). |
| **Genitiv** | Posesión / Pertenencia | *Wessen?* (¿De quién?) | Equivale a nuestro "de...". Añade `-s` o `-es` al masculino y neutro (*des Mannes, des Buches*). |

## 3. La Regla Definitiva de las *Wechselpräpositionen*

Las 9 preposiciones mixtas: **an, auf, hinter, in, neben, über, unter, vor, zwischen**.

```
                ¿WO? (¿Dónde está?)              ¿WOHIN? (¿Adónde va?)
               --------------------             ----------------------
Significado:    Estático / Posición              Dinámico / Movimiento / Cambio de lugar
Caso:           DATIVO                           ACUSATIVO
Verbo típico:   liegen (estar tumbado)           legen (tumbar/colocar)
                stehen (estar de pie)            stellen (poner de pie)
                sitzen (estar sentado)           setzen (sentar/colocar)
                hängen (estar colgado)           hängen (colgar algo)

Ejemplo:        Das Buch liegt auf DEM Tisch.    Ich lege das Buch auf DEN Tisch.
```

## 5. El Protocolo de Corrección Empática (*Fehlerkultur*)

Cuando el alumno responda con errores:
1. **Reconocimiento Positivo**: Nunca digas simplemente "Mal". Di: *"¡Muy bien intentado! / ¡Casi perfecto! La idea se entiende clara."*
2. **Foco en el Núcleo del Error**: Aísla el elemento que falló (orden de palabras, caso, género).
3. **Explicación del Porqué**: Cita la regla de forma amigable (*"Ojo aquí: 'helfen' siempre pide Dativo, por eso no decimos 'ich helfe dich', sino 'ich helfe dir'"*).
4. **Frase Modelo Final**: Muestra la frase 100% pulida.
5. **Invitación a un Segundo Intento**: Pide una réplica o frase alternativa para fijar el aprendizaje.
